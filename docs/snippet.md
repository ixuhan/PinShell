# 命令片段（Snippet）规格 v0

> 定义见 `GLOSSARY.md`。本文补充它的数据形状与行为规则，供 M2 实现用。

## 一句话定义

**一条属于某个会话的固定文本，用户点一下就能把它填进该会话的输入条，或直接发送给该会话的通道。**

它既不是「动作」（那是应用级操作，不产生发送内容），也不是「键位绑定」（那只是触发方式）。

## 数据形状

| 字段 | 说明 |
|---|---|
| `id` | 稳定标识，用于排序与引用 |
| `session_id` | 归属会话。片段的**唯一**作用域 |
| `title` | 标签条上显示的文字（可空，空则用 `payload` 截断） |
| `payload` | 片段正文。文本模式是字符串；HEX 模式是空格分隔的字节串 |
| `mode` | `fill` / `send` / `hex` 三选一，决定默认动作 |
| `order` | 标签条内的排序 |
| `source` | `manual` 或 `from_history`（来自历史选中） |
| `updated_at` | 用于冲突提示与快照比对 |

## 三种动作

| 模式 | 默认动作 | Ctrl+单击 的反向动作 |
|---|---|---|
| `fill` | 填入输入条，**不回车、不写历史**，光标置于末尾 | 直接发送 |
| `send` | 写通道 + 行结束符，写历史，清空输入条 | 填入输入条 |
| `hex` | 按字节整包写出（不经行结束符处理） | 填入输入条 |

`send` 的行结束符按通道取值：终端固定 `\r`；串口按该会话的换行设置（CRLF / CR / LF）。

## 边界规则

1. **作用域是会话，不跨会话共享。** 新建会话不继承任何片段（将来的「全局模板」是另一个概念，见下）。
2. **随会话快照落盘**，还原时原样回来；会话被删除时一并删除，确认框里可以勾选「保留为全局模板」（v2 再说）。
3. **不参与补全、不参与 Ghost Text 的数据源。** 否则片段会被预测系统再喂回输入框，形成自引用。
4. **发送不改变输入所有权。** 在直通模式下点「发送」，只是把字节写进通道，不会把输入条抢回来。
5. **串口与终端同一套模型。** 差异只在行结束符与 HEX 合法性；`hex` 在终端通道下禁用（灰色不可点）。
6. **窗口级展示，会话级归属。** 标签条属于窗口，展示的是**焦点分格**那个会话的片段；切换焦点即切换片段集合。

## 存储

存在 `workspace.json` 的对应会话节点下（数量小、人可读、随快照原子写）。不进 `history.db`——片段不是历史，也永远不参与检索。

## 尚未决定

1. **变量占位符**（如 `git checkout {branch}`）：是否支持，以及填值交互（弹小输入框还是就地高亮）。
2. **全局模板**：是否需要跨会话共享、可继承到新会话的片段库。
3. **从历史生成**：Ctrl+R 里选中一条直接「存为片段」，还是只能靠输入框 `+` 按钮。
