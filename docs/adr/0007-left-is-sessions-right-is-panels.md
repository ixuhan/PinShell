# 0007 左栏是会话栏，右栏是功能栏

- 状态：**左栏部分被 ADR 0008 取代**（2026-11-22）——左栏固定为项目栏，决策 1 与 8 不再成立；右栏 = 功能栏与面板同权部分继续有效。
- 相关：ADR 0004、ADR 0006、ADR 0008、GLOSSARY「项目栏」「功能栏」「串口列表」

## 背景

左栏一直同时放着会话列表和串口列表：两件事没有关系，却共享同一列宽度与收起状态；串口列表还带着自己的行内 ＋ 与右键菜单，于是「新建串口会话」有三条入口（行内 ＋、双击行、右键），而对话框里的端口是只读的——端口由「点了哪一行」隐式决定。右栏是写死的两段（快捷指令 + 文件），文件被特例成永远撑满剩余高度，`files-folded` 这类补丁因此散落在样式与脚本里。

需求把这件事重新划了一遍：左栏只放会话，串口列表搬进右栏与快捷指令、文件并列，列表只做展示；右栏放哪些面板、以什么顺序放，交给全局设置。

## 决策

1. **左栏 = 会话栏。** 只放独立会话或项目分格；不属于会话的东西不再进这一栏。
2. **右栏 = 功能栏。** 承载三个功能面板：快捷指令、串口列表、文件。
3. **三个面板完全同权。** 没有特殊栏：各自记住高度（默认 220 / 180 / 260，可拖、双击复位）、可折叠、可隐藏、可排序。
4. **最后一个「可见且展开」的面板吃剩余高度。** 它由 `rightBarUi` 挂 `rb-fill`，高度交给 flex、高度手柄隐藏；全部折叠时下面留空，不把别的面板撑开。文件不再是恒定撑满的那一个。
5. **可见性与顺序是一份窗口级布局。** 存 `localStorage` 的 `pinshell.rightbar`，所有会话与项目共用。设置里三行始终都在：勾选只控制可见性，顺序表包含没勾选的项，勾掉再勾回位置不变。
6. **取消勾选 = 这个面板不存在。** 不渲染、不占高、停止自己的后台刷新（串口轮询 / 文件自动刷新）；三个全不勾时整条功能栏消失，标题栏的折叠按钮置灰，回到右栏的入口只剩全局设置。
7. **串口列表只读。** 只枚举端口与设备描述，并标出当前焦点串口会话占用的端口；没有行内 ＋、没有右键菜单、单击与双击都不做事。
8. **创建入口回到「新建会话」。** 会话栏 ＋ 菜单末尾加「新建串口会话…」；项目模式先问落点、再开对话框，端口在对话框里从枚举列表挑（也可手输）。这条菜单项不支持拖到分格——端口要到对话框里才确定。
9. **即时生效，没有取消。** 勾选与排序立刻落到右栏，与语言、主题一致；`×` 与 `Esc` 只是关闭，不回滚。

## 后果

- 对话框的端口输入框从只读变成可编辑 + 下拉；「点哪行建哪个口」的隐式关联消失。
- I4（同一串口不允许两个热会话）第一次在界面上看得见：列表高亮当前焦点会话占用的口。
- 三个面板的高度共用 `clampPanelHeight` 一份夹取规则（下限 120px、上限为可用高度的 70%）；串口与快捷指令原先各自的实现退役。
- 串口轮询与文件自动刷新的「可运行」判定多一条「面板没被勾掉」，与整栏收起、窗口隐藏同级。
- `pinshell.files` 存档多一个 `height`；`files-folded` 特例类与左栏的串口相关样式退役。
- 右栏收起后的 26px 竖条上写「功能」而不是「文件」；标题栏按钮的文案统一成「功能栏」。

## 替代方案

- **串口列表留在左栏，只改标题**：改动最小，但左栏仍然混着两件事，「功能栏」这个概念立不住，右栏也没有统一的面板模型。
- **保留串口列表的双击创建**：能保住「所见即所选」，但与「只做列表展示」冲突，而且两套创建入口正是操作复杂的来源。
- **文件永远是撑满的那一个**：面板顺序可配置后，「最后一块」在不同配置下指代不明；改成「最后一个展开的面板吃剩余」规则更少，代价是文件栏第一次需要自己的高度。
